# VNBOT_AUTO_EAMT5 — bộ cài đặt

Làm EA cho MetaTrader 5 cùng đội AI.

**Tải bản mới nhất:** mở mục [Releases](../../releases/latest) → tải file `VNBOT_AUTO_EAMT5_Setup_<phiên bản>.exe`.

- Mỗi bản phát hành có ghi **SHA-256** — kiểm trước khi cài theo trang hướng dẫn cài đặt đi kèm.
- Sau khi cài, app tự báo khi có bản mới (trang License → Cập nhật).
- Hỗ trợ: hotro@vnboteamt5.com

Repo này chỉ chứa bộ cài đặt, không chứa mã nguồn.
